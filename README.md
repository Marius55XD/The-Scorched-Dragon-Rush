# The Scorched Dragon Rush

## Overview

**The Scorched Dragon Rush** is a 2D platformer game built with Unity. The player navigates through challenging levels, avoiding obstacles and enemies while racing to the finish.

## Academic Context

This project was developed as part of a **Continuous Assessment (CA)** at **Monaghan Institute**. It was a **team-based project**, with all members collaborating on design, development, and testing.

## Features

- 2D platformer gameplay
- Custom animations and sprites
- Audio effects and background music
- Checkpoint system
- Multiple scenes/levels

## Built With

- [Unity](https://unity.com/) — Game engine
- C# — Scripting language
- TextMesh Pro — UI text rendering

## Getting Started

1. Clone the repository.
2. Open the project in **Unity** (recommended version: check `.vsconfig` for compatibility).
3. Open the desired scene from `Assets/Scenes/`.
4. Press **Play** in the Unity Editor to run the game.
